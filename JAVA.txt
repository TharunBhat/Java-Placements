Abstraction

It is the process of hiding unnecessary details and showing necessary information

Advantages
to protect the data from unauthorised persons (hackers)
2. it improves the performance
3. it reduces the readability
-----------------------------------------------------------------
Java provides two ways to achieve the abstraction
1. abstract class
	abstract is a key word used to create the abstract class
	in abstract class, we cannot create object

abstract methods:
1. it is used to hide the unnecessary/internal data
2. it does not contain implementation

2. interface
	it is key word used to create the interface class
	it is used to achieve the abstraction
