Asymptotic Notation :
It is used to calculate the mathematical representation of the program.

1. Big O() notation :
It is formal way to express the upper bound of the algorithm.
It follows the worst case complexity.

2. omega Ω() notation :
It is formal way to express the lower bound of the algorithm.
It follows the best case complexity.

3. theta Θ() notation :
It is formal way to express the average bound of the algorithm.
It follows the average case complexity.

Big O() notation :
O(1) - Constant complexity -> 0th index, direct
O(n) - Linear Complexity -> Last index, access all element
O(n^2) - Quadratic -> Nested for loop
O(n^3) - Cubic -> nested for loop, have one sub loop
O(n!) - factorial depends on input

Important cases :
O(log n) - logarithmic, Binary search and binary search tree
O(n log n) - merge sort and quick sort

With the help of notation we can calculate the program performance.
The performance is based on time and space.

Time Complexity :
Time taken for a execution of a program.

space complexity :
space taken for a execution of a program.

Implementation of SLL :
insert()
public void insert(int data){
        Node hello=new Node(data);
        if(head==null){
            head=hello;
            tail=hello;
        } else {
            tail.next=hello;
            tail=hello;
        }
    }

search()
public void search(int val){
        int p=0;
        Node n=head;
        while(n!=null){
            if(n.data==val){
                p=1;break;
            }
            n=n.next;
        }
        if(p==1)
            System.out.println("Yes");
        else 
            System.out.println("No");
    }

delete()
public void del(int tar){
        if(head.data==tar){
            head=head.next;
        }
        else{
            Node n=head;
            while(n.next.data!=tar){
                n=n.next;
            }
            n.next=n.next.next;
        }
    }
